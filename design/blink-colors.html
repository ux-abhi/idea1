Apple’s colours, Blink’s restraint

Blink uses Apple’s own system colours and materials, so it looks native in light and dark, follows your accent colour on the Mac, and adapts to Increase Contrast and Reduce Transparency for free. Premium comes from restraint: mostly neutrals, one accent, colour only when it means something.

Continuous corners

Squircle curves everywhere (RoundedRectangle(style: .continuous)). Circles only for avatars and buttons.

Concentric radii

Inner radius = outer radius − padding (28 − 10 = 18), so nested shapes look parallel.

Hairlines

Design sync
Standup

Separators are one physical pixel (0.5 pt) in the separator colour, never 1 pt grey.

Specular edge

A 1 px light line on the top inner edge of cards and tiles. Strong in light (70% white), faint in dark (10%).

Elevation

Light: two soft shadows (tight + wide). Dark: no shadows, a lighter surface instead.

Glow with a reason

Only live things glow: mood eyes, countdown rings, the listening state. 55% colour, 10 pt blur, inside the shape.

Numbers

SF Pro Rounded, semibold, tabular figures for big numbers (like Fitness and the Watch). Digits roll when values change.

Symbols

SF Symbols in hierarchical rendering, matched to text weight; symbol effects (bounce, pulse) only on state changes.

Accessibility and code

Built to adapt

  • Increase Contrast: system colours switch to their high-contrast versions automatically; custom glows turn off.
  • Reduce Transparency: all glass and materials become solid surfaces.
  • Reduce Motion: no glow pulses, no digit rolls; crossfades only.
  • Contrast: text 4.5:1 minimum; status is never colour alone (each pill also has a word or symbol).
  • Source of truth: design/tokens.json in the repo, mapped to SwiftUI names.
// SwiftUI: tokens map to Apple semantic colours, never hex
extension Color {
    static let blinkSurface   = Color(.secondarySystemGroupedBackground)
    static let blinkHeadsUp   = Color.mint      // time
    static let blinkImportant = Color.red       // needs you
    static let blinkThinking  = Color.indigo    // Claude working
    static let blinkDone      = Color.green
    static let blinkAttention = Color.orange
}

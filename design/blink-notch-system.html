Mascot

Glossy bot, panda eyes

The white glossy shell from your first references, with the panda’s duo-tone eyes: black glass patches with light eyes inside. No nose, no mouth.

  • Duo-tone stays fixed: black patch, light eye. Only the eye’s tint and shape change with mood.
  • In the notch the black hardware already is the patch, so only the two light eyes appear.
  • Eyes tilt slightly toward each other, which keeps them from reading as a pause icon.

Drop zoneNotch stretches toward the dragged fileSpring 0.3 s / 0.7Outline only
  • Springs everywhere, and they can be interrupted: a new event mid-animation continues from the current shape and speed instead of restarting.
  • One moving thing at a time: the shape moves first, then the content. Never both at full speed.
  • Only cheap properties move: size of the notch shape, opacity and transforms. Text never reflows during an animation.
  • 120 Hz on ProMotion Macs, drawn by the system compositor; nothing redraws while Blink is at rest.
  • Matched geometry: a card that opens into the app window keeps its identity, so it grows into place instead of reappearing.
  • Haptics: a light trackpad tap on approve and when a drop is accepted.
  • Battery: countdowns are drawn by the system; rings and bars animate only on a value change; calm mode stops everything.

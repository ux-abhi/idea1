Install Blink.

Free, for MacBooks with a notch running macOS 26. It takes about three minutes once you have the download.

Blink isn't public yet. Join the waitlist and we'll email you when it's ready to download. This guide is here so you know what to expect.

Download Blink.dmg

One extra step, the first time. This build isn't notarized by Apple yet, so the first time you open Blink, macOS stops it until you confirm in System Settings. Step 4 shows how. We'll ship a notarized build soon; until then macOS asks once.

Install

  1. Download Blink.dmg.Use the link in your waitlist email. It lands in your Downloads folder.
  2. Drag Blink into Applications.Open Blink.dmg and drag the Blink icon onto the Applications folder. Then eject the disk image.
  3. Open Blink.Open your Applications folder and double-click Blink. macOS says it can't check Blink and doesn't open it. Click Done, not Move to Trash.
  4. Allow it in System Settings.Open System Settings › Privacy & Security and scroll down to Security. Next to “Blink was blocked”, click Open Anyway, enter your Mac password, then click Open Anyway once more. You only do this the first time.

Set up

Blink opens with a short setup. You need no code and no terminal.

  1. Server.Click Sign in with Supabase. Blink creates a free Supabase project in your own account and installs everything it needs. If something interrupts it, it picks up where it stopped. Already run a Supabase server? Choose I already have a server and paste its address and publishable key.
  2. Account.Create or sign in to the login on your own server. Each Mac is registered with your server, not with Pexilim.
  3. Calendar.Allow Calendar access. Your next meeting shows up in the notch.
  4. About you.Optional. Tell Blink a little about your day so its suggestions fit.

For AI, paste a free Groq key during setup. Add a Claude or OpenRouter key later in Settings › Connections if you want them. Keys are stored as secrets on your server and never shown again.

Then press ⌃⌥Space to ask Blink anything, or ⌃⌥V for your clipboard.

Verify the download

To check that your copy is exactly the one we published, open Terminal and run:

shasum -a 256 ~/Downloads/Blink.dmg

The result should match this line:

SHA-256: published here with the first release

Remove Blink

Quit Blink and move it from Applications to the Trash. Your data on your own server stays there until you delete it; deleting the Supabase project removes all of it.
